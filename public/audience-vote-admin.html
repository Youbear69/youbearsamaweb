ระบบจัดการโหวตคนดู (Audience Vote Control)

ควบคุมการเปิด-ปิดหน้าเว็บ, เปิด-ปิดรอบการโหวต, รีเซ็ตรอบ และตั้งค่า Stream Deck

หน้าเว็บโหวต: เปิดให้เข้าได้ รอบการโหวต: เปิดรับคะแนน คนดูโหวตแล้ว: 0 คน
เปิดหน้า Overlay (OBS) ↗

ผลคะแนนและเปอร์เซ็นต์สด (12 ราศี)

ลิงก์ควบคุมสำหรับ Stream Deck (Direct HTTP Trigger)

สามารถนำลิงก์ด้านล่างไปใส่ในปุ่ม Stream Deck (เลือก Action: Website / Open URL หรือ API Request) เพื่อกดปุ่มสั่งการได้ทันทีจากโต๊ะสตรีม หรือกดปุ่ม "ทดสอบกดทำงาน" เพื่อลองสั่งการได้ทันที

เลือกโดเมนลิงก์:
1. ควบคุมการเข้าถึงหน้าเว็บโหวต (Page Access):
สลับเปิด/ปิดหน้าเว็บ (Page Toggle): http://localhost:3000/api/audience-vote/streamdeck/page-toggle
บังคับเปิดหน้าเว็บ (Page Open): http://localhost:3000/api/audience-vote/streamdeck/page-open
บังคับปิดหน้าเว็บ (Page Close): http://localhost:3000/api/audience-vote/streamdeck/page-close
2. ควบคุมรอบการลงคะแนน (Voting Round):
สลับเปิด/ปิดรอบโหวต (Round Toggle): http://localhost:3000/api/audience-vote/streamdeck/toggle
บังคับเปิดรอบโหวต (Round Open): http://localhost:3000/api/audience-vote/streamdeck/open
บังคับปิดรอบโหวต (Round Close): http://localhost:3000/api/audience-vote/streamdeck/close
รีเซ็ตคะแนนรอบนี้ (Round Reset): http://localhost:3000/api/audience-vote/streamdeck/reset

ประวัติรายชื่อคนดูที่ลงคะแนน (Voters Log)

ลำดับ เวลาที่โหวต ชื่อผู้โหวต (Username) ราศีที่เลือก
